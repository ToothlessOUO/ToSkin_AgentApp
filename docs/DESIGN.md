# DESIGN — ZONE 皮肤的改造方向与设计语言

两个端口（DSH `package/`、ZCode `for_zcode/`）共同实现的**目标规范**。
改视觉先改这份，再按 [../AGENTS.md](../AGENTS.md) 的同步协议落到两端；
两端测试守着这里写下的地板。历史原点：DSH ZONE 皮肤 v1.0.0（黑橙硬件风）。

## 皮肤的一句话

黑橙硬件风：机器的机身与键帽纸、模切的贴纸、警戒条纹、LED 设备条 ——
把聊天界面当成一台**正在运行的设备**来打扮，而不是一张网页。

## 底盘（Chassis）—— 机身不随配色动

两块画布，机身恒定，只有强调色随配色换（和硬件配色一个道理）：

| 画布 | 底面 base | 卡片 layer1 | 浮层 layer2 | 墨水 ink | 侧栏 |
| --- | --- | --- | --- | --- | --- |
| Blacksite（夜） | `#2c2927` | `#373330` | `#423d3a` | `#f8f3e8` | `#232020` |
| Cream（昼） | `#e8e1d1` | `#f5efe4` | `#dbd3c2` | `#171310` | `#ded5c4` |

- ink-dim（弱化墨水）：夜 `#ccc1b0` / 昼 `#645a4b`；line（刻线）：夜 `#544c46` / 昼 `#c8bfa9`。
- 贴纸纸面 cream `#efe9db`、石墨 graphite `#141110` 为常量。
- 派生面（hover/active/line-soft/rule/code/signal）全部由底盘按固定公式推导
  （两端各自实现，公式见 DSH `schemeFor()` / ZCode zone.css derived 段）。

## 配色（Colorways）—— 唯一可动的强调色

| 配色 | 夜 · 强调 | 昼 · 强调 |
| --- | --- | --- |
| Zone orange（默认） | `#ff6f1a` | `#e2560d` |
| Ember | `#ff4632` | `#c62c1b` |
| Hazard | `#ffc61a` | `#a8770a` |
| Cobalt | `#4d94ff` | `#1f5fd6` |

配色只出现在"发光/强调"的位置：主按钮、焦点环、选中板、用户消息板、
透镜与尾迹、托架、警戒带、LED。**底盘永远不掺配色**（唯一例外：投影用
配色的深色 mix —— "按键的侧面"，见下）。

## 亮板法则（lit plates）—— 皮肤的核心语法

凡是"被点亮"的表面 = **配色实心板 + 字面量白墨 + 向外辉光**，全皮肤只有一种白：

- 用户消息板（DSH `--dsw-specific-bubble` / ZCode `--color-user-message-bubble` → brand）；
- 选中的会话/任务行（DSH `_sessionRow_selected` / ZCode `group/task-item|task-row.bg-selected`）；
- 按下的按钮、贴纸上的激活片、全局文本选区（反白保持可见）。

夜 zone 橙 2.78:1、夜 hazard 黄 1.57:1 的白墨是 owner 接受过的取舍 —— 报告，不修。
板内上墨一律走**变量作用域**（局部重定义前景变量），不走 `!important` 链。

## 光与影

- **投影** = `mix(brand, black, 夜.58/昼.45)`（按键的侧面，不是光）；
  三层：贴边 1px + 近落 + 远落。只许 `rgb(var(--*-rgb) / α)` 字面量，
  color-mix 不进 box-shadow（一个坏 mix 作废整条列表）。
- **背光**（输入卡）= 中性发丝线 + 热核 `mix(brand,#fff,.22)` + 配色外晕 ——
  从背后点亮的一块，不是浮起来的键。
- **板辉光** = 纯向外（`0 0 4px α1, 0 0 9px α.6` 一类），无 rim 无 inset。

## 纸面肌理（氛围层）

挂在会话面板上（两端各自测量锚定）：7px 半调网点（上浓中淡下回）、
侧栏/标题栏 7.5px 接缝投影（峰值 α.2，角落交叉渐隐）、四只配色托架角
（顶对落在**消息区顶线**之下 —— 标题/tab 属于 chrome，不属于纸面）。

## 指针：透镜与尾迹（皮肤的招牌动效）

半调网格上方，方形大网点跟随指针：

- **亮头**：位置直接取自指针事件，**不做缓动跟随**（光点永远在鼠标下），
  软圆掩罩半径 100px，峰值 α 10%；
- **尾迹**：canvas 按同一 7px 网格画同样 4px 方点，**从样本表每帧重绘**
  （每格取最新一次覆盖的亮度，寿命 1100ms 到期精确不画 —— 位图自衰减
  到不了零，是明确否决过的方案）；峰值 α 8.5% 恒低于亮头；
- 出聊天带（标题线下、输入卡上）淡出；`prefers-reduced-motion` 与动效 off 停用。

参数两端必须一致：PITCH 7 / INSET 1.5 / DOT 4 / BRUSH 100 / STEP 16 /
LIFE 1100 / CORE .085 / LEVELS 32 / JUMP 160 / KEEP 640。

## 字体

UI 面 Bahnschrift（DIN 风），标签面 Cascadia Mono；中文由 Noto Sans Mono CJK SC
承担（2:1 mono 网格，机器级安装一次：`font-lab/install-fonts.ps1`，装完重启宿主）。

## 设备语汇（控制台 / 设备条 / 贴纸）

- 控制台：小芯片（`ZONE/0n`）弹出面板 —— 配色 / 画布 / 动效 / 半调开关；
  快捷键 `Ctrl+Alt+Z`（配色）`X`（画布）`H`（藏芯片）。
- 设备条：脉冲 LED + 警戒带 + 配色编号 + 图纸号（会话标识）。
- 贴纸：cream 纸 + 石墨描边 + 警戒胶带 + 四色样块。
- 光标：24px SVG 自绘集（石墨箭头 + 配色描边、奶油描边线稿字形），
  wait/help 等系统态保持原生。

## 状态色（功能性，不随配色）

| 状态 | 夜 | 昼 |
| --- | --- | --- |
| success | `#4fdc8c`（深墨字） | `#22763f`（白字） |
| destructive | `#ff5a45`（白字 ≥3:1） | `#b32d1f`（白字） |
| warning | `#ffc61a`（深墨字） | `#8a6408`（白字） |

对比度地板：正文 7:1 / 次级 4.5:1 / 弱化 3:1 / 边线可见 1.15:1 / 功能墨水 3:1。
终端 ANSI 16 色保持宿主语义，只动底盘 / 光标 / 选区。

## 动效三挡

`full`（全部）/ `quiet`（LED 变慢、入场缩短）/ `off`（停）；
系统 `prefers-reduced-motion` 永远映射为 off。过渡时长普遍 ≤ .3s，
硬件感来自"快而利落"，不来自飘。

## 已决策的不做

- toast 不染色（宿主只有表面变量，染橙会在昼画布翻车）；
- 终端 ANSI 不动（可读性语义）；
- DSH 的完成提示音不盲目移植到 ZCode（无事件桥，见各端路线）；
- 不引入第二个白色、第二张板色表、任何哈希类选择器。
